# wartergen
Warcraft III map terrain generator.

What can this application do?

In a nutshell - generate terrain from images.
You can take any image and paint a map with it.

- Create terrain tiles.
- Cliffs(terrain levels)
- Water
- Heights
  
  All listed above features already exist as a number of custom scripts and outdated apps across the web.
Wartergen combines all the logic into one standalone solution. You just select a map and images, click "Draw Terrain" button and that`s it.
No hassle with files and directories, no need to manually pack/unpack via MPQ editor, Wartergen does this all under the hood.
